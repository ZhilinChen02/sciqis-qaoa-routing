# Archived development material

These files document superseded development stages. They are retained for
provenance but are not installed, tested, or exposed as course commands.

- `legacy_core_pipeline/`: the earlier Q1-versus-warm-start orchestration and
  plotting scripts.
- `q2r/`: the adaptive Q2-R controller, tests, and preregistration notes.
- `sealing_controllers/`: one-shot scripts that produced immutable result
  roots. They must not be rerun as ordinary course commands.
- `warm_start_tuning/`: the superseded epsilon/multistart tuning study.
- `SOURCE_Q2_MAPPING.md`: historical implementation provenance.

Generated result data is deliberately not stored here. The three immutable
result roots remain under `results/` with their own hash manifests.
