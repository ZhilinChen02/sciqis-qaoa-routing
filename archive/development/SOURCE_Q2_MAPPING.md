# Archived Q2 source provenance and extraction map

## Discovery result

The requested path `Q-RouteBench-v3.3-AM1` exists, but its checkout contains no
Git commit and its Python package files are empty placeholders. The adjacent
Q-RouteBench evidence checkout maps the validated baseline algorithms to
`Q-RouteIR-LearnQ-RouteIR-Learn/qrouteir/qaoa_baselines/`. That implementation
was inspected read-only and cross-checked against its historical DTU lineage.

The target project does not import or require either external repository.

## Intentional DTU adaptations

- The benchmark corridor and benchmark platform were not copied.
- The existing 7-node DTU graph, 14-edge encoding, exact solver, decoder, and
  QUBO/Ising implementation remain authoritative.
- The source method expects a current feasible route. Here it is generated by
  a deterministic lightest-reachable-edge greedy rule, without reading the
  exact optimum.
- The fixed DTU penalty is 6 because exhaustive analysis gives
  `A_crit=5`; benchmark penalty rules were not imported.
- Sampling-only metrics were omitted because this project reports exact
  statevector probabilities.
- A Qiskit circuit equivalent was added only to validate the matrix evolution
  and measure circuit resources. The optimization remains exact statevector,
  matching the source algorithm.

## Deliberately excluded

No benchmark registry, multi-instance runner, frozen result table, admission
logic, manifest layer, scheduler, multiprocessing system, hardware execution,
or additional quantum solver was brought into the course repository.
